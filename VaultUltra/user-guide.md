# FamilyVaultUltra User Guide

## Getting Started

FamilyVaultUltra helps you organize your family's important documents and information in one secure place. When you first open the app, six starter folders are created for you: **Legal, Financial, Medical, IDs, Property,** and **Personal**. Each one comes with a list of suggested items to help you get started — nothing is required, and you can skip anything that doesn't apply to you.

## Folders

Folders are the main way to organize your information.

- **Smart folders** (the original six) come with suggested items and helpful field templates built in.
- **Custom folders** can be created anytime with the **+** button on the Folders screen — useful for anything that doesn't fit the built-in categories.
- **Suggested Items** appear at the top of a smart folder. Tap one to create it (with fields already set up for that type), or swipe left to skip it if it doesn't apply to you.
- **Delete a folder** by swiping left on it. Items that also belong to another folder are not deleted — only the folder itself is removed.

## Items

An item is a single thing you're keeping track of — a bank account, a passport, an insurance policy, and so on.

- Tap **+** inside a folder to create a new item. If the folder has specific suggested types (like Passport or Trust Documents), you'll see those as options; otherwise you'll see general-purpose types like Bank Account or Login/Account.
- Choosing a type automatically sets up the right fields for that kind of item (for example, a Bank Account gets fields for the bank name, account number, and routing number).
- An item's **type** can't be changed once it's created — this keeps your organization consistent. You can always create a new item if you need a different type.
- Items are grouped by type within each folder, so all your bank accounts, for example, appear together.
- **Delete an item** by swiping left on it in the folder list.

## Custom Fields

- Tap directly into any field's value to edit it — there's no separate edit screen.
- **Sensitive fields** (like account numbers or passwords) are marked with a dot pattern by default. Tap the eye icon at the top of the item to reveal or hide all sensitive fields at once.
- Add your own fields with **Add Field**, choosing a name, a type (text, date, currency, or number), and whether it should be treated as sensitive.

## Attachments

Each item can hold photos, scanned documents, or files.

- **Add Photo** — attach an existing photo from your library.
- **Scan Document** — use your camera to scan a physical document. FamilyVaultUltra automatically detects the edges and corrects the perspective for you. (This requires a physical device — it isn't available in previews or simulators.)
- **Attach File** — import a PDF or other document directly from the Files app or iCloud Drive.
- Tap any attachment to view it. Photos and scans open in a zoomable image viewer; PDFs and other documents open in a full document viewer.
- Scanned and photographed text is automatically recognized in the background, which makes it searchable (see Search, below).

## AI-Assisted Field Extraction

If you've scanned a document with recognizable text, you can swipe left on that attachment and choose **Extract Info** to have key details suggested automatically — for example, pulling a policy number or account name out of a scanned insurance card.

This feature is optional and requires you to add your own Anthropic API key in **Settings**. Suggested fields are always shown to you for review first — nothing is saved until you confirm which ones to keep.

## Search

Use the **Search** tab to find anything across your vault — item titles, notes, and text recognized from scanned documents are all searched together.

## Sharing a Folder

Tap the person icon next to any folder in the Folders list to invite someone to that folder — a family member, for example. You can invite them by Messages, Mail, or by copying a link directly.

Once a folder is shared, tapping the same icon shows you who has access and lets you manage or remove participants.

## Security

- FamilyVaultUltra is protected by Face ID (or your device passcode) every time you open it, and re-locks automatically if you leave the app.
- Your information is stored in your own private iCloud account and is encrypted. FamilyVaultUltra has no servers of its own and cannot access your data.

## Settings

- **Anthropic API Key** — add or remove your own key for the optional AI-assisted extraction feature.
